## Deskripsi Dashboard

**Dashboard Penjadwalan Hemodialisis Medika Central** merupakan prototype dashboard berbasis HTML, CSS, dan JavaScript yang dirancang untuk membantu petugas dalam memantau dan mengelola jadwal hemodialisis.

Dashboard menampilkan jadwal pasien berdasarkan **sesi pagi dan sesi siang**, penggunaan mesin HD, status pelayanan pasien, serta beberapa peringatan otomatis yang dapat membantu petugas mengidentifikasi risiko dalam penjadwalan.

Dashboard ini menggunakan **data 100% sintetis** dan dibuat untuk keperluan praktikum. Dashboard bukan merupakan sistem pelayanan klinis dan tidak menggunakan data pasien nyata.
